# File Organizer
A Python script that automatically sorts files into folders based on their extension.

## Features
- Automatically sorts files into folders based on their extension
- Duplicate detection - if a file with the same name already exists, it renames it instead of overwriting it
- Leaves existing folders untouched
- Unsupported file types are moved to an `Others` folder

## How to use
- Make sure that you have Python installed on your computer
- Drop the script into any folder, open your cmd, and run:
```
python file_organizer.py
```
- Or you could just double click on it and it's going to run and get the job done in no time
